## Preprocessing Unstructured Data

### Normalizing the content

**Format Diversity**  Documents come in a variaty of formats (pdf, word, epub, markdown).  
**Common Format** The first step in preprocesing is to convert raw documents into a common format that identifies common document elements, like titles and narative text.  

**Normalization Benefit** Normalized format allows any document to be processed in the same way, regardleess of the source format.
 - Filterign out unwanted elemtns, like header and footer.  
 - Chunking document elements into sections.
